# An ASL Transcription ML Project
* Implemented an ML model to determine ASL gestures through **hand landmark detections**, intended to be further developed for **transcription services** for the deaf and hard of hearing in virtual meetings
* Created dataset through **cv2** and processed the data by recording hand landmark coordinates in a **2D array**
* Utilized the **RandomForestClassifier** to develop and train the predictive model and a **live video feed** to deploy the model
